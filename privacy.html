Конфиденциальность

Ниже описано, что делает этот сайт и какие данные обрабатывает приложение Slipstream VPN.

Последнее обновление: 5 ноября 2026 года

Сайт загрузки

Сайт — статические HTML-, CSS- и JavaScript-файлы. Он не использует аккаунты, формы, рекламные идентификаторы, аналитические скрипты или собственные cookies.

Чтобы показать актуальные версии и загрузки, страница отправляет браузерный запрос к публичному GitHub Releases API. При переходе по ссылкам релизов или скачивании файлов запрос обслуживается GitHub. GitHub может обрабатывать сетевые журналы согласно своей политике конфиденциальности.

Сайт не запрашивает и не передаёт ссылки VPN-профилей, пароли, UUID или ключи серверов.

Данные в Android-приложении

Импортированные профили, URL подписок, выбранный сервер и настройки маршрутизации сохраняются локально на устройстве в зашифрованном виде с помощью AES-GCM и Android Keystore.

При обновлении приложение обращается к GitHub Releases API; при загрузке новой версии получает APK из релиза и проверяет его пакет, версию и сертификат подписи. Токен доступа GitHub в приложении не хранится.

URL HTTPS-подписки загружается с указанного пользователем сервера при импорте и обновлении. Поставщик подписки может видеть сетевой запрос. Сам VPN-сервер, к которому вы подключаетесь, обрабатывает трафик в соответствии со своими настройками и правилами.

Приложение не отправляет разработчику диагностические события или содержимое профилей через собственный сервер. Системные журналы Android и библиотек могут храниться на устройстве.

Настольное приложение

Настольный клиент держит импортированные профили в памяти процесса. Для запуска sing-box создаётся временный файл конфигурации с данными профиля; приложение удаляет его после отключения или закрытия. Не завершайте процесс принудительно во время подключения, если это возможно.

Ваш выбор

Вы можете удалить сохранённые профили в приложении или удалить локальные данные Slipstream из системных настроек устройства. Чтобы узнать, как сообщить об ошибке, не раскрывая секреты профиля, см. инструкцию по устранению проблем.

Изменения и контакты

Эта страница может обновляться вместе с приложением. Вопросы о конфиденциальности можно задать через GitHub Issues. Не публикуйте там секретные данные VPN.

iЭто описание объясняет работу данного проекта и не заменяет юридическую консультацию. Политики GitHub и VPN-провайдера устанавливаются соответствующими сторонами.
